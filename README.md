# Pollito · web

Web personal estática (HTML + CSS + JS, sin dependencias de build). Se abre con `index.html`.

- `index.html` — portada, sobre mí, setup, clips y redes
- `cs2.html` — mi config de CS2 y descarga de `download/config.7z`
- Clips: edita los atributos `data-*` de cada `.clip` en `index.html`
- Canciones: edita la lista `playlist` en `js/script.js`
